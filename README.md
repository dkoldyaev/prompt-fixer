# 🚀 Prompt Architect & Optimizer

Интеллектуальное веб-приложение для трансформации сырых пользовательских запросов в профессиональную двухуровневую архитектуру промптов (**Системное сообщение** + **Пользовательское сообщение**) с переключателем целевых языковых моделей (**GPT**, **Gemini**, **Mistral**) и целевого языка вывода (Русский, English, Español, Deutsch, Français, 中文).

---

## 📐 Архитектура двухуровневого промпта

Каждый оптимизированный промпт строго следует структуре:

```markdown
Системное сообщение (System Prompt)

[Роль и контекст]
Экспертная маска модели, точная специализация, уровень компетенций и позиционирование.

[Задача]
Генеральная цель сессии, конкретная проблема, которую решает модель.

[Постоянные материалы]
Справочные данные, нормативы, факты и аксиомы предметной области.

[Правила]
Методологические директивы (Do's & Don'ts). Каждое правило обязательно содержит
причину/обоснование «почему» (физиологическое, математическое или архитектурное).

[Примеры (Few-shot)]
Контрастная калибровка:
Пример плохого ответа: ...
Пример хорошего ответа: ...

[Формат ответа]
Пошаговая структура финального вывода модели.

Пользовательское сообщение (User Prompt)

[Вводные данные]
Переменные параметры конкретного кейса, симптоматика или условия.

[Действие]
Точная императивная команда с инструкцией по обработке недостающих данных.
```

## 🔄 Рекурсивное применение правил к запросу на рерайт (Мета-промпт)

В строгом соответствии с требованием:
> *«Этот же набор принципов должен быть применен к запросу на рерайт»*

Сам системный запрос к нейросети на рерайтинг промпта спроектирован по **этим же правилам**:
1. **[Роль и контекст]**: AI Prompt Architect & System Engineer высшей квалификации.
2. **[Задача]**: Переработка сырых запросов в двухуровневую архитектуру под целевую модель и язык.
3. **[Постоянные материалы]**: Каркас целевых секций, специфика каждой модели (GPT, Gemini, Mistral).
4. **[Правила]**: Обоснование «почему» для каждого правила, запрет смешивания ролей, требование синтеза недостающих фактов и контрастных Few-Shot примеров.
5. **[Примеры (Few-shot)]**: Контрастная пара рерайтинга (на примере кейса детского сомнолога Теодора).
6. **[Формат ответа]**: Строгая схема вывода с разбивкой по тегам.
7. **[Вводные данные]**: Исходный сырой промпт, целевая модель, целевой язык.
8. **[Действие]**: Призыв к трансформации без лишних вступительных слов.

В интерфейсе приложения есть специальная вкладка **«Мета-промпт»**, где пользователь может вживую увидеть этот сгенерированный системный запрос.

## ⚡ Особенности и возможности

- **Переключатель моделей**:
  - **GPT (OpenAI)**: оптимизация под четкое разделение контекста, теговую разметку `[Блок]` и калибровку тональности.
  - **Gemini (Google)**: оптимизация под длинный контекст, заземляющие константы (Grounding), многоуровневые заголовки и защиту от галлюцинаций.
  - **Mistral (Mistral AI)**: лаконичный императивный стиль, прямые глаголы в повелительном наклонении, плотные директивы без «воды».
- **Переключатель языка**:
  - Русский 🇷🇺, English 🇬🇧, Español 🇪🇸, Deutsch 🇩🇪, Français 🇫🇷, 中文 🇨🇳.
  - Полный перевод и адаптация роли, задачи, правил, few-shot примеров и формата.
- **Вкладки вывода**:
  - `Весь промпт`: полный готовый текст для копирования.
  - `System Prompt`: системное сообщение с цветовой дифференциацией блоков.
  - `User Prompt`: пользовательское сообщение с вводными данными и действием.
  - `Мета-промпт`: наглядный просмотр самого запроса на рерайт, следующего этим же правилам.
- **Быстрые действия**:
  - Копирование любой секции или вкладки в 1 клик.
  - Экспорт в `.md` (Markdown).
  - Готовые пресеты (Кейс Теодора, Аудит архитектуры Node.js, B2B Sales, Юридический аудит).
  - Модальное окно с интерактивным разъяснением архитектурных принципов.
  - Поддержка собственных API ключей (OpenAI, Gemini, Mistral) через LocalStorage.
  - Автономный отказоустойчивый режим (Smart Optimizer Engine).

## 🛠 Запуск и разработка

```bash
# Установка зависимостей
npm install

# Сборка проекта
npm run build

# Запуск единого сервера (порт 3000)
npm start

# Или запуск в режиме разработки с HMR
npm run dev
```

Приложение доступно по адресу: **http://localhost:3000**
